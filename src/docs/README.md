# Leasing brochures

Add a PDF named `<property-slug>-brochure.pdf` and a "Download brochure" button appears
on that property's Available space section:

- `mchenry-village-brochure.pdf`
- `northgate-plaza-brochure.pdf`
- `lakeside-shopping-center-brochure.pdf`

Brochures are public once deployed. Leave out rents, NOI, tenant sales, or anything
that should stay internal.
